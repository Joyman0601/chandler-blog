> 系列第 1 篇。做应用不需要会推导反向传播，但要能讲清几个核心直觉：Transformer 凭什么能堆这么大、注意力机制在算什么、采样参数怎么调、模型为什么会一本正经地胡说。这一篇就把这些地基打牢。

## Transformer 一句话直觉

一句话：**让序列里每个词都能直接看到其他所有词，并按相关性加权融合信息。**

和 RNN/LSTM 对比就清楚了：

- RNN 串行处理，信息一个词一个词往后传，距离一远就遗忘，而且无法并行。
- Transformer 并行处理整个序列，任意两个词之间的距离都是 1，可以并行训练。

这里有个关键结论：**正因为训练可以并行，才喂得下海量数据、堆得起大模型**。所谓「大」模型成为可能，根因就在「训练可并行」这一点上。

### 三种结构

- **Encoder-only（BERT）**：擅长理解、双向看上下文，适合分类和做 embedding。RAG 里用的 bge embedding 就属于这一类。
- **Decoder-only（GPT / Qwen / LLaMA）**：擅长生成，从左往右预测下一个词，是当前主流。
- **Encoder-Decoder（T5）**：翻译这类「输入一段、输出另一段」的任务。

为什么主流是 Decoder-only？生成任务只需要预测下一个 token，结构统一简单；scaling 效果好；训练目标单一、数据近乎无限。

> 小坑提醒：Encoder 的「Encode」是**编码 / 表示学习**，不是密码学的「加密」。它适合做 embedding，是因为双向能充分理解整句语义。

## Attention 与 QKV：图书馆比喻

注意力机制最好用查资料来理解：

- **Query（Q）**：你心里的问题。
- **Key（K）**：每本书的标签。
- **Value（V）**：书里真正的内容。

过程是这样的：当前词发出一个 Query，和每个词的 Key 算点积相似度，softmax 成一组权重，再按权重对所有 Value 加权求和，得到一个融合了上下文的新表示。

举例：「小猫追球……因为**它**很兴奋」。处理「它」时，它和「小猫」的相似度高，于是融合进小猫的信息，模型就理解了指代关系。

**为什么能建模长距离依赖**：任意两个词直接算相似度，路径长度永远是 1，不会随距离衰减。这正是 RNN 做不到的。

### 多头注意力

多头注意力相当于派出多个「专家」并行地从不同角度看同一句话——有的看指代、有的看语法、有的看情感，最后把各自的结论拼接起来。这样模型能同时捕捉多种关系，思路类似 CNN 里的多个卷积核。

## 采样参数：temperature / top-k / top-p

模型每一步实际输出的是「下一个词的概率分布」，采样参数控制怎么从这个分布里挑词。

- **temperature**：低 → 分布变陡，保守、可复现；高 → 分布变平，多样但容易胡说。
- **top-k**：只在概率最高的 k 个词里挑。
- **top-p（核采样）**：把词按概率从高到低累加，凑够 p 就在这批里挑，比 top-k 更自适应。

在 RAG 场景里，通常把 temperature 调低（0~0.3），追求忠于检索材料、可复现。需要创意发散时才调高。

## token、上下文窗口与 KV Cache

- **token**：模型处理的最小单位（BPE 子词）。中文一个字大约 1~2 个 token，比英文更费 token——因为英文有空格天然分词、子词复用率高，而中文没有空格、字符集又大。计费和长度限制都按 token 算。
- **上下文窗口**：一次能看的最大 token 数（输入 + 输出共享）。
- **KV Cache**：缓存前面词的 K、V，避免每生成一个词都重算一遍，用来加速推理。代价是吃显存，上下文越长占用越大。
- **中间遗忘（lost in the middle）**：长上下文里，开头和结尾的信息利用得好，中间容易被忽略。这给 RAG 一个启示——**把最相关的检索片段放在 prompt 的开头或结尾**，这也是重排（rerank）的价值之一。

## 幻觉：成因与缓解全景

**为什么会幻觉**：模型的本质是预测下一个 token，目标是「流畅」而不是「真实」；训练数据本身可能有错或过时；模型缺少一个明确的「我不知道」机制。三者叠加，它就会编。

**缓解手段全景**：

1. **RAG**：把外部知识检索进来，给模型真实依据。
2. **提示约束**：明确要求「没有依据就说不知道」。
3. **解码控制**：把 temperature 调低，减少发散。
4. **后校验**：生成时附上来源引用，可追溯。
5. **微调对齐**：通过 SFT / DPO 让模型更倾向于诚实。

实际系统里这些手段通常叠加使用，而不是只靠一种。

## 小结

这一层的目标不是会算，而是能讲清「为什么」：为什么 Transformer 能做大（训练可并行）、注意力在做加权求和、采样参数如何调、token 为什么中文更费、幻觉怎么来又怎么缓解。地基打好了，下一篇就进入这条路线的招牌——RAG 检索质量。
