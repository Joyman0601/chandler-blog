## 为什么要做个人网站

个人网站可以把技术笔记、项目复盘和长期学习记录沉淀到一个稳定的位置。相比把内容分散在不同平台，自己的站点更适合持续维护，也方便后续绑定域名和扩展功能。

## 第一版目标

第一版先完成四个核心页面：首页、文章、项目、关于。文章使用 Markdown 编写，部署使用 Cloudflare Pages，域名后续从阿里云购买并绑定。

```bash
npm create astro@latest chandler-blog
cd chandler-blog
npm run dev
```

## 后续计划

后续可以继续补充文章目录、RSS、站点地图、评论系统、访问统计和深色模式。第一阶段重点是先让网站可访问、可更新、可持续写作。
