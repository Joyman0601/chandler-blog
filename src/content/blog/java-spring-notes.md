## 学习重点

Java 和 Spring 的学习不只是在记 API，更重要的是理解工程结构、依赖管理、配置方式和常见问题的定位方法。

## 可以长期整理的主题

- Spring Boot 项目结构
- MyBatis 与数据库访问
- 接口设计与参数校验
- 日志、异常和测试
- 部署与性能排查

## 记录方式

每篇笔记尽量包含背景、问题、解决过程和最终结论。这样后续遇到类似问题时，可以快速复用自己的经验。
